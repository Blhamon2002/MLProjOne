# MLProjOne
Project for Machine Learning Class at NWMSU

My Project has shifted a lot during this milestone. Hardly anything stayed the same. Going with my original project proposal, I wanted to see if I could predict who/what countries would win gold medals in the olympics based on a series of attributes of where the games were hosted, what the physical attributes of the athletes were, etc. 

That being said, I found that almost all of the data I could find about the olympics were string formatted in nature. I did eventually find some numerical data such as height, weight, and age but I didn't have many data fields to work with.

That caused me to switch to a different subject entirely. I chose to look at World Bank Information regarding economics and see if I could predict the GDP per capita based on information such as the interest rate reported that year, the unemployment rate, etc. I found this to be much more feasible and easy to work with. From there, I was able to complete the necessary steps of this project milestone.

I have explored and played with the data set some, I created training/test sets, and performed some calculations to determine the performance of my model as well.
